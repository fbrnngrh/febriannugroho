## Getting Started

Next.js 16 brings significant improvements to the developer experience.

### Server Components

Server Components are now the default, which means better performance out of the box.

### Key Takeaways

- Use Server Components by default
- Add 'use client' only when needed
- Leverage streaming for optimal UX
