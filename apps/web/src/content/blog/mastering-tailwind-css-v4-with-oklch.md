## Why OKLCH?

OKLCH provides perceptually uniform colors that look consistent across different hues.

### Setting Up

Tailwind v4 supports OKLCH natively through CSS-first configuration.

### Dark Mode

OKLCH makes dark mode color balancing much simpler because lightness is separated from chroma and hue.
